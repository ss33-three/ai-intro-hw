# 八皇后问题 AI 协作工程化实践
## 项目背景
本项目是《人工智能导论》课程作业，借助Cursor AI编程工具完成八皇后问题的工程化实现，核心考察AI工具运用与工程项目构建能力。

## 项目结构

## 实现思路
1. 核心算法：采用回溯法遍历所有可能的皇后摆放位置，通过剪枝排除同列、同斜线的非法位置；
2. AI协作：借助Cursor完成代码编写、测试用例设计、Bug定位与修复；
3. 工程化：遵循Python项目规范，拆分源代码与测试代码，保证代码可测试、可维护。
